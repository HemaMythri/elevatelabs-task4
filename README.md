# Mobile-Friendly Website Using CSS Media Queries

## Project Overview

This project is a responsive landing page developed using HTML5, CSS3, and JavaScript as part of a Web Development Internship Task.

The website adapts seamlessly across desktop, tablet, and mobile devices using CSS Media Queries. Additional features such as a hamburger navigation menu, dark mode toggle, smooth scrolling, and interactive animations have been implemented to enhance user experience.

---

## Features

- Responsive Navigation Bar
- Hamburger Menu for Mobile Devices
- Dark Mode Toggle
- Hero Section with Call-to-Action Button
- About Section
- Features Section with Responsive Cards
- Statistics Section
- Call-to-Action (CTA) Section
- Footer Section
- Smooth Scrolling Navigation
- Hover Effects and Animations
- Fully Responsive Layout using CSS Media Queries

## Responsive Design

The website uses CSS Media Queries to adjust layouts and styling based on screen size.

```css
@media (max-width: 768px)
```

Responsive improvements include:

- Navigation menu converted to hamburger menu
- Hero section stacked vertically
- Feature cards displayed in a single column
- Statistics section adjusted for smaller screens
- Improved mobile readability and spacing
